# Phishing Awareness Training

**CodeAlpha Cyber Security Internship — Task 2**

## About the Project
This project is a beginner-friendly phishing awareness training module created to explain how phishing attacks work and how to recognize and avoid them.

## Objectives
- Understand phishing and social engineering.
- Identify suspicious emails and fake websites.
- Recognize common phishing techniques.
- Learn safe practices to protect personal information.
- Test knowledge using a short quiz.

## Topics Covered
- Introduction to phishing
- Warning signs in phishing emails
- Recognizing fake websites and suspicious links
- Social engineering tactics
- Common forms of phishing
- Real-world example: Operation reWired
- Prevention, reporting, and recovery
- Interactive knowledge-check questions

## Project Files

## Tools Used
- Microsoft PowerPoint
- Clipchamp

## Learning Outcome
This project helped me understand common phishing techniques and the importance of verifying messages, checking website domains, and reporting suspicious activity.
