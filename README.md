# CodeAlpha Task 2: Phishing Awareness Training

## Project Overview

This project was developed as part of my **CodeAlpha Cyber Security Internship**. It focuses on educating users about phishing attacks, helping them recognise suspicious messages and fake websites, and encouraging safe online practices.

The project includes a PowerPoint presentation and an interactive web-based quiz to make learning about phishing simple and engaging.

The quiz contains five multiple-choice questions covering common phishing scenarios and safe online behaviour. It provides a score after the user submits their answers.

## Project Objectives

- Understand what phishing is and how it works.
- Recognise suspicious emails and potentially fake websites.
- Learn about social engineering tactics used by attackers.
- Understand safe practices for handling suspicious links and attachments.
- Encourage verification of unusual requests involving sensitive information or payments.
- Reinforce learning through an interactive quiz.

## Topics Covered

### 1. Introduction to Phishing
An explanation of phishing attacks and how attackers attempt to trick people into revealing sensitive information or taking unsafe actions.

### 2. Recognising Phishing Emails
Warning signs such as unexpected messages, urgent requests, suspicious links, unusual sender addresses, and unexpected attachments.

### 3. Identifying Fake Websites
Checking website domains, being cautious with unfamiliar links, and understanding that HTTPS or a padlock icon alone does not guarantee that a website is legitimate.

### 4. Social Engineering
How attackers use urgency, impersonation, trust, and fear to influence people's decisions.

### 5. Prevention and Safety Practices
- Verify unexpected requests through a separate trusted channel.
- Visit official websites directly rather than following suspicious links.
- Avoid opening suspicious attachments.
- Never share passwords or sensitive information in response to unverified messages.
- Report suspicious messages through the appropriate channel.
- Use multi-factor authentication where available.

### 6. Interactive Quiz
A five-question quiz that tests understanding of phishing, suspicious email attachments, website security indicators, and safe verification practices.
